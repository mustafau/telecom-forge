# Retrospectives

Generated reports belong at `retrospectives/<year>/<YYYY-Www>.md`.

`2026/2026-W44.md` is the empty location for that week. It is not a claim that a retrospective has been run. Create one with:

```bash
pnpm forge retro --week 2026-W44 --propose
```

That command writes the report and proposal files. It does not change skills and it does not merge anything.
