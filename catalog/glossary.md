# Glossary

Local definitions used by this metarepository. They are not a restatement of TM Forum specifications.

| Term | Meaning here |
|---|---|
| Product | A commercial offering a customer can order. |
| Service | A configured technical capability delivered for a product. |
| Resource | A physical or logical thing a service depends on. |
| Order | A customer request to add, change, or remove a product. |
| Service order | The service-layer request that fulfills part of an order. |
| Fulfillment | The work that makes a requested service available. |
| Assurance | The work that keeps a live service healthy. |
| Task | A Telecom Forge work definition under `tasks/<id>/`. |
| Run | One attempt to validate, implement, verify, and optionally publish a task revision. |
| Control SHA | The trusted metarepo commit that supplies workflows, skills, catalog, and publisher code. |
| Task SHA | The commit on the developer branch that supplies `task.yaml` and `task.md`. |

Last verified: 2026-10-27, against this repository's catalog rather than an external standards document.
