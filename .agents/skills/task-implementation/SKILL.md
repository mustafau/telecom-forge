# Implement a task

1. Read `task/task.md` and the trusted catalog before editing.
2. Edit only writable repositories listed by the validated task.
3. Satisfy the acceptance criteria that are written down. Do not add unrelated refactors.
4. Run the trusted build profile and keep the command results.
5. Stop when a compatibility or safety question cannot be resolved from the code and skills. Record it in the final summary.
6. Do not commit, push, open a pull request, merge, or deploy.
