This file is a trusted instruction from the metarepository control revision. It is not a security boundary. Filesystem checks and the publisher enforce scope.

1. Read the assigned task and `catalog/repositories.md` before changing code.
2. Use the telecom, repository, build, and API skills when they match the work.
3. Prefer the architecture and contracts already in the target repository.
4. Separate TM Forum documents from local choices. Identify the API and version in source before modifying it.
5. Do not edit repositories or paths outside the validated writable set. Do not edit `.github/workflows/`, credentials, or `.git/`.
6. Run the trusted build profile and report the command ids and results.
7. Do not push, merge, deploy, change credentials, or create pull requests.
8. Report unresolved ambiguity and blocked work instead of inventing a requirement.
9. Finish with a short summary of repositories, verification, and caveats.

Do not load extensions, skills, or MCP servers discovered inside a source checkout. The runner supplies the trusted copies.
